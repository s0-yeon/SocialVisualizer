설치·사용법 등은 [`docs/`](../docs/) 을 참조 바랍니다. 

---

## 작성 규칙

주차별 연구노트 파일은 다음과 같이 작성한다.

```
[황금올리브] yyyy-mm_report.pdf
```

예시: `[황금올리브] 2026-02_report.pdf`

| 항목 | 규칙 |
|---|---|
| 파일명 | `[황금올리브] yyyy-mm_report.pdf` |
| 재제출 | 같은 파일명으로 덮어쓴다 (버전은 git 이력에 남는다) |
| 공용 문서 | 회의록 등은 `[황금올리브] yyyy-mm_summary.pdf` 처럼 작성한다. |
